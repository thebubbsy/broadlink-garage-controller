Fastest: download the ready-made Shortcut
⬇️ Download Shortcut
  1. Open the download → it imports into the Shortcuts app. Tap Add Shortcut.
  2. Open it in the editor, tap the URL inside Get Contents of URL and replace it with your private link (copied above).
  3. Done — say "Hey Siri, open garage door".
Build it yourself (2 minutes)
  1. Copy the link above.
  2. Open the Shortcuts app → tap +.
  3. Add action Get Contents of URL → paste the link.
  4. Add action Show Result (so Siri tells you it worked).
  5. Name it Open garage door → Done.
